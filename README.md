# Tasks｜阶段一 GitHub & Markdown 作业仓库
> 仓库说明：本仓库为阶段一学习作业，不同主题内容分开存放为独立文件，方便查阅。

## 📑 文件目录索引
| 文件名称 | 内容简介 |
| `github-learn-note.md` | Geek概念、GitHub、Markdown理论学习笔记 |
| `markdown-syntax-practice.md` | Markdown各类语法实操练习 |
| `trouble-record.md` | 学习过程踩坑记录与解决方案 |

## ✅ 作业规范说明
1. 文件命名：全部英文命名，不使用中文文件名
2. 排版规范：段落空行分隔，标题分层，区分段落换行/软换行
3. 仓库管理：了解Fork、Pull Request协作机制；国内访问GitHub不稳定，分批提交文件

## 🎯 学习目标
掌握 GitHub 仓库基础使用、Markdown 标记语法，后续用于C语言代码与学习笔记版本管理。
